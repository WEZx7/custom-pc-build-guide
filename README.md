# Custom PC Build Guide

A practical PC hardware documentation project covering component selection, compatibility, assembly, BIOS setup, Windows installation, drivers, testing, and troubleshooting.

## Project Overview

This guide documents the complete process of planning, building, configuring, testing, and troubleshooting a custom desktop PC.

The goal is to demonstrate practical PC hardware knowledge and IT support skills through a structured build workflow.

## Build Workflow

### 1. Component Selection

Main components:

- CPU
- Motherboard
- RAM
- GPU
- Storage
- Power Supply
- CPU Cooler
- PC Case
- Case Fans

Important factors:

- Performance requirements
- Budget
- Upgrade path
- Power requirements
- Cooling requirements
- Physical compatibility

### 2. Compatibility Checks

Before assembly, verify:

- CPU socket matches the motherboard
- Motherboard supports the selected CPU
- RAM type is compatible with the motherboard
- GPU fits inside the case
- CPU cooler supports the CPU socket
- PSU provides enough wattage
- PSU includes required CPU and GPU power connectors
- Case supports the motherboard form factor
- Storage interfaces are supported

## PC Assembly Checklist

Recommended assembly order:

1. Install the CPU
2. Install RAM
3. Install M.2 storage
4. Install CPU cooler
5. Install motherboard into the case
6. Install power supply
7. Connect motherboard power
8. Connect CPU power
9. Install GPU
10. Connect GPU power
11. Connect front-panel connectors
12. Connect case fans
13. Perform cable management
14. Inspect all connections before powering on

## First Boot Checklist

After powering on:

- Confirm CPU and case fans are spinning
- Check motherboard debug LEDs
- Confirm the system reaches BIOS
- Check CPU temperature
- Confirm RAM is detected
- Confirm storage drives are detected
- Confirm CPU is detected correctly

## BIOS Setup

Recommended BIOS checks:

- Verify CPU information
- Verify installed memory
- Enable XMP or EXPO if supported
- Check CPU temperature
- Confirm storage devices
- Configure boot order
- Check fan settings
- Enable TPM if required
- Enable Secure Boot when needed

## Windows Installation

Basic installation process:

1. Create a bootable Windows USB drive
2. Select the USB drive from the BIOS boot menu
3. Start Windows Setup
4. Select the correct storage drive
5. Install Windows
6. Complete initial Windows setup
7. Run Windows Update

## Driver Installation

Recommended driver installation order:

1. Motherboard chipset driver
2. Network drivers
3. GPU driver
4. Audio driver
5. Other motherboard drivers
6. Windows updates

## System Testing

After setup, verify system stability.

### Hardware Checks

- CPU temperatures
- GPU temperatures

- Fan operation
- Network connectivity

### Stability Testing

Possible tests include:

- CPU stress test
- GPU stress test

- Storage health check
- Gaming or workload test

## Common Troubleshooting

### PC Does Not Power On

Check:

- PSU power switch
- Power cable
- 24-pin motherboard connector
- CPU power connector
- Front-panel power button connector

### PC Powers On But No Display

Check:

- Monitor input
- HDMI or DisplayPort cable
- RAM installation
- GPU installation
- GPU power cables
- Motherboard debug LEDs

### CPU Debug LED

Possible checks:

- CPU power connector
- CPU seating
- Bent socket pins
- BIOS compatibility
- CMOS reset

### VGA Debug LED

Possible checks:

- GPU seating
- GPU power cables
- Display cable
- Different PCIe slot
- Integrated graphics if available

### Storage Not Detected

Check:

- SATA or power cable
- M.2 installation
- BIOS storage settings
- Different SATA port
- Drive health

## Safety Guidelines

Before working inside a PC:

- Shut down the computer
- Disconnect power
- Turn off the PSU
- Avoid working on carpet when possible
- Ground yourself before touching components
- Never force connectors into place
